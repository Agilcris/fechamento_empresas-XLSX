# 🏢 AgilCRis — Levantamento Financeiro para Baixa de Empresa

Repositório da ferramenta de suporte para encerramento de atividades empresariais (MEI, ME e LTDA). Este projeto faz parte do ecossistema de soluções da **AgilCRis Consultoria**.

## 🎯 Objetivo
Facilitar o processo de encerramento de empresas, permitindo que o empreendedor identifique débitos, obrigações e pendências fiscais antes de formalizar a baixa, evitando a transposição de dívidas para o CPF.

## 🛠️ O que o produto oferece
* **Organização de Fluxo**: Extrato mensal consolidado.
* **Mapeamento de Riscos**: Identificação de dívidas com bancos, fornecedores e fisco.
* **Metodologia AgilCRis**: Checklist de 6 etapas para uma baixa segura.
* **Suporte**: Orientação baseada em consultoria especializada em Simples Nacional.
